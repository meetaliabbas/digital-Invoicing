# Multi-Tenant FBR Digital Invoicing & Fiscalization Platform

A multi-tenant platform for issuing, validating and fiscalizing invoices with the Federal Board of Revenue (FBR).

## Redesigned Pages

The `src/pages/PlatformRedesign` folder contains a refreshed UI pattern (icon-rail navigation, tenant switcher, card-based layouts) for the platform's core screens, built with functional components and local array-based data:

- `Login.js` — split-screen sign-in
- `Dashboard.js` — platform overview with KPIs and fiscalization trends
- `InvoiceList.js` — searchable, filterable invoice register
- `CreateInvoice.js` — guided multi-step invoice creation and posting
- `BuyerProfiles.js` — buyer directory
- `Reports.js` — tax and compliance analytics

Available at routes `/platform/login`, `/platform/dashboard`, `/platform/invoices`, `/platform/invoices/create`, `/platform/buyers`, and `/platform/reports`. The color palette and logos are unchanged from the existing theme (`src/assets/scss`, `src/assets/images`).
