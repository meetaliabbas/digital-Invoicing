PROJECT SUMMARY
================
Multi-Tenant FBR Digital Invoicing & Fiscalization Platform
Generated: 2026-08-07

OVERVIEW
--------
This is a React 18 single-page application (react-scripts / CRA) that
demonstrates a redesigned, multi-tenant platform for FBR (Federal Board
of Revenue, Pakistan) digital invoice fiscalization. The original large
legacy codebase was stripped down to a focused demo centered on the
"PlatformRedesign" module (src/pages/PlatformRedesign).

TECH STACK
----------
- React 18.2, React Router DOM 6.22
- Reactstrap 9.2 / Bootstrap 5.3
- node-sass for SCSS styling
- react-scripts 5.0.1 (Create React App tooling)
- Dev server runs on port 3009 (npm start)

APPLICATION STRUCTURE
----------------------
Routing entry:      src/Routes/index.js
Layout shell:        src/pages/PlatformRedesign/RedesignLayout.js
Shared context:      src/pages/PlatformRedesign/TenantContext.js (tenant switcher)
Mock data:            src/pages/PlatformRedesign/data.js
Branding:             src/pages/PlatformRedesign/BrandMark.js

PAGES / ROUTES (9 total)
-------------------------
1. /platform/login             - Login.js            - Auth screen (email/password, mock)
2. /platform/dashboard         - Dashboard.js         - Platform overview: KPIs, fiscalization
                                                         trend chart, tenants-by-plan breakdown,
                                                         recent invoices table
3. /platform/invoices          - InvoiceList.js       - Searchable/filterable list of fiscalized
                                                         invoices
4. /platform/invoices/create   - CreateInvoice.js     - New invoice creation form
5. /platform/buyers            - BuyerProfiles.js     - Buyer/customer profile management
6. /platform/tenants           - Tenants.js (NEW)     - Tenant directory: status, plan tier,
                                                         city, branch counts, workspace switch
7. /platform/reports           - Reports.js           - Reporting/analytics screen
8. /platform/notifications     - Notifications.js(NEW)- FBR submission alerts (success/warning/
                                                         rejection filters)
9. /platform/settings          - Settings.js (NEW)    - Business profile, bank details, and
                                                         FBR sandbox/production API integration
                                                         settings
